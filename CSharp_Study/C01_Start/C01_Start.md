```csharp
using System;

namespace C01_Start
{
    class Program
    {
        private static void Main(string[] args)
        {
            Console.WriteLine("Hello, C#");
            Console.WriteLine("Hello, Unity");
            Console.WriteLine("Hello, Unity!!");

            Console.WriteLine("Hello, SBS");
            Console.WriteLine("Hello, SBS");
            Console.WriteLine("Hello, SBS");
            Console.WriteLine("Hello, SBS");
            Console.WriteLine("Hello, SBS");
        }
    }
}
```

- 여러줄 동시에 편집 : 알트+ 쉬프트 + 방향키
- Console.WriteLine : 한 줄 출력(\n포함)
- Console.Write : 한 줄 출력(개행 문자 미포함)
